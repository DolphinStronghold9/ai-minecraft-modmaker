# MORTAR.md

Mortar reads this file before every turn in this world. Put it in the world folder, next to `level.dat`.

## Building

- Our palette is spruce, cobblestone, stone bricks and deepslate. Don't bring in other wood.
- Roofs are stepped or use stairs. No flat roofs.
- Light every build so mobs can't spawn inside.

## Hands off

- Nothing within 20 blocks of spawn (0 64 0).
- Don't touch the village at -400 64 120.

## Datapacks

- Use the namespace `hillside` for everything.
